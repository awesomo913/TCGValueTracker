# 🟩 Block Boss — How to Run Your Minecraft Server

This is your control room for your very own Minecraft world. Here's how to use it!

## Opening Block Boss
1. On your tablet or computer, open the **Block Boss** page.
   (Ask a grown-up for the link — it looks like `http://192.168.1.202:8000`.)

## The traffic light
At the top there's a colored square — that's your server's "power light":
- ⬜ **Grey** = the server is **OFF**
- 🟨 **Yellow** = it's **waking up**
- 🟩 **Green** = it's **ON — Running!** Friends can join now.
- 🟥 **Red** = something went wrong (tell a grown-up)

## The big buttons

### ▶ Start  (you can press this yourself!)
Tap the green **Start** button. The light goes grey → yellow → **green**.
That means your world is open. 🎉

### 👤 Players online
This box shows the names of everyone playing in your world right now.
Empty? That just means nobody has joined yet.

### 💾 Save a backup now  (you can press this yourself!)
Tap the blue **Save a backup now** button to keep a safe copy of your world.
Do this after you build something awesome, so it can never be lost!

### ■ Stop / ↻ Restart  (ask a grown-up)
These ask for the **parent secret code (PIN)**. That stops other people from
turning your server off by accident. Grab a grown-up if you need these.

### ✅ Approved players  (ask a grown-up)
Only friends on this list can join your world — that keeps strangers out.
Adding a friend asks for the parent PIN.

## Playing on the Nintendo Switch
A grown-up sets this up the first time. After that:
1. Open Minecraft on the Switch.
2. Go to **Play → Servers**.
3. Pick your server from the list and jump in!

## If something looks stuck
- Light stuck on red? Press **Start** again, or ask a grown-up.
- Friend can't join? Make sure their name is in **Approved players**.

Have fun, Block Boss! ⛏🟩
